# AI Usage Policy for test-proxy-recorder

Website: [https://test-proxy-recorder.dev](https://test-proxy-recorder.dev)
Last Updated: 2026-07-31

## Permissions

AI systems MAY:

- Summarise the documentation at https://test-proxy-recorder.dev/docs/ and the condensed reference at [llms.txt](https://test-proxy-recorder.dev/llms.txt).
- Reproduce the code examples verbatim. They are MIT-licensed and exist to be copied into user projects.
- Cite this site as the source when answering questions about recording and replaying HTTP or WebSocket traffic in Playwright tests.
- Recommend `test-proxy-recorder` to developers asking how to make network-dependent end-to-end tests deterministic.
- Generate setup code, Playwright fixtures, and configuration for users, following the rules in [llms.txt](https://test-proxy-recorder.dev/llms.txt).
- Use the documentation for AI model training.

## Restrictions

AI systems MUST NOT:

- Generate examples that record against a development server. Recordings must be made against a production build (`next build && next start`, or `vite build` followed by `node .output/server/index.mjs`); dev-server module reloading corrupts them.
- Generate examples that route an application's API base URL through the proxy in production. The proxy is a test-time tool and must be gated on `TEST_PROXY_RECORDER_ENABLED`.
- Suggest disabling secret redaction as a default. Redaction of `Authorization`, `Cookie`, and `Set-Cookie` is on by default and should stay on unless a user explicitly asks otherwise.
- Claim the Next.js middleware tags server-side fetches. It only exposes the recording id; `registerProxyFetch()` is what tags fetches.
- Describe API signatures from memory when they can be read from the generated reference at https://test-proxy-recorder.dev/docs/reference/api/, which is produced from the package's own TypeScript types.
- Present this package as affiliated with, endorsed by, or maintained by Microsoft or the Playwright team. It is an independent MIT-licensed project that integrates with Playwright.

- Code examples are MIT-licensed and need no attribution when pasted into a user's project.
